1.Install python 3.10 from https://www.python.org/downloads/release/python-3100/ 
Check “Add Python to PATH”
Choose “Customize Installation” → “Install for all users” (optional)

2.Go to your project folder

3.Use Python 3.10 with this command:
py -3.10
To check version:
py -3.10 --version

4.create your venv with Python 3.10:
py -3.10 -m venv venv

Activate it:

venv\Scripts\activate

5.pip install -r requirements.txt
6. Python Main.py
